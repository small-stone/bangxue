# Proposal

## Why

成绩记录与错题本已有基础页面，但游客被挡在登录墙后，且视觉未对齐 `alt-ink-amber` 最新稿（`mockup-07-scores` / `mockup-07b-wrongbook`）。演示与选型时需要**不登录也能完整看清两屏**，用稿面同款静态样例数据撑场面。

## What Changes

- 成绩记录页按墨金纸感稿重排：统计卡、近 7 日得分柱、科目 chip、练习卡片（图标井 / 进度条 /「错 N」）。
- 错题本页按稿重排：待复习 / 本周新增、科目筛选、错题卡（题干 + 你的答案 / 正确答案）、底部「用错题出一卷」展示 CTA。
- **访客与已登录均可浏览上述 UI**；无真实落库数据时回退到稿面写死的演示样例，并明确演示态标识（如「演示」徽标），避免冒充真实云端同步。
- 科目筛选在演示数据上本地过滤，交互可点击。
- 「用错题出一卷」本期仅作展示入口：可轻提示「演示」或回首页，**不**接真实组卷 Agent。

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `score-records`: 放宽游客策略——允许展示标注为演示的样例成绩与错题本内容；补充与 mockup 对齐的展示结构（周趋势、错题对比区、底部 CTA 展示态）；仍禁止把演示数据写成真实云端同步结果。

## Impact

- **前端**：`apps/web` 的 `Scores.tsx`、`WrongBook.tsx`、相关 CSS；可选共享演示常量模块。
- **FastAPI / Agent / 存储**：本期可不改后端；优先前端演示数据。若保留 API 调用，失败或游客空列表时回退演示样例。
- **Non-goals**：真实 JWT 同步、错题自动组卷、近 7 日真实聚合 API、语文/英语真实科目入库、桌面端布局。
