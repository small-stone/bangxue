# Design

## Context

见 `proposal.md` 的 Why。现状：`ALLOWED_BOOK` 与前端 `canContinue` 写死一年级上册；`draft.term` 只有 `'上册'`。`book/小学/数学/人教版` 有 12 本 PDF。切分器已支持「第 N 单元」和孤行汉字序号；四年级下册等旧版是目录式「1 四则运算」，正文用阿拉伯数字起章，当前会切分失败。入库仍是 `python -m ingest ingest --pdf …` 一次一本，向量为百炼 1024 维。

## Goals / Non-Goals

**Goals:**

- 12 本小学数学人教版在切分成功的前提下全部写入 `textbook_chunks`。
- 出题与选题覆盖这些已入库册的按单元路径。

**Non-Goals:**

- 不改向量检索方式，不做对话出题，不扩到初中或其他科目。

## Decisions

### 元数据从路径与文件名解析，不维护手写 12 行清单

约定布局：`book/小学/数学/人教版/<文件名>.pdf`。文件名中匹配 `一年级`…`六年级` 与 `上册`/`下册`。学段固定小学，科目数学，版本人教版。解析失败的文件记入批量失败列表，不猜测。

备选：YAML 清单。更稳但要与文件名双处维护。目录已规范，选解析。

### 切分同时支持修订版与旧版序号

在 `split.py` 增加与孤行汉字对称的规则：孤行 `1`–`12`（可含全角），下一行非空且不像页码时，单元名为「第 N 单元」+ 课题，或直接用「N 课题」与目录一致。跳过目录页中「纯数字页码」行，避免把目录当成正文起点；已有的 TOC 页码后缀过滤继续保留。`学习准备`、`总复习`、`数学广角` 等若以独立标题出现，按现有或同等一级结构纳入，避免整本无单元。

备选：只解析目录页再按页码切。更准但对提取噪声敏感。先用正文序号，目录辅助校验可留到失败书再补。

### 出题白名单改为「库里有块」

删除单一 `ALLOWED_BOOK`。`list_units` / `load_unit_text` 要求：`stage=小学`、`subject=数学`、`edition=人教版`，`grade` 为一年级至六年级，`term` 为上册或下册，且该五元组在表中有行。否则 400/404。生成提示改为「你是{grade}小学数学出题助手」，仍只根据给定课文。

### 前端学期与可继续条件

`Draft.term` 改为 `'上册' | '下册'`，选题页增加学期芯片。`canContinue`：小学 + 数学 + 人教版 + 合法年级 + 学期。范围页失败时展示接口错误（未入库）。默认年级可改为一年级或保持三年级，但未入库时下一步进范围页会看到空单元/错误——批量入库完成后再验收全年级。

### 状态存什么

```
批量入库
  扫描 book/小学/数学/**/*.pdf
       │
       ▼
  解析五元组 → ingest 一本（embed → replace_book）
       │
       ▼
  textbook_chunks（按五元组隔离）

家长出题
  选题（年级+学期）→ GET units → 选单元
       │
       ▼
  load_unit_text（按单元名，非向量）→ generate_questions → quiz 内存 id
```

- Checkpointer / `thread_id`：本期不用。
- 业务：仍用进程内 quiz id；多册只影响读哪些 chunk。
- 密钥：继续 `bailian_api_key`、`QUIZ_MODEL`、`EMBEDDING_*`，不写进仓库。

批量入库是本地 CLI，可能连续十余次 embedding，需可用的百炼配额与较长等待；失败书单独重跑该本即可。

## Risks / Trade-offs

- [旧版 PDF 提取噪声导致误切或漏切] → 每本入库后打印单元名列表；抽查四年级下册、六年级上册；失败不写入。
- [12 本 embedding 费用与耗时] → 批量串行；已成功册跳过可选（默认同五元组覆盖，与现规则一致）。
- [长课文超 8000 字截断] → 保持现有上限，避免提示过长；不在本期做智能摘取。
- [与 `add-grade1-quiz-screens` 规格冲突] → 本变更规格以全小学数学为准；归档一年级变更时以本规格为准。

## Migration Plan

1. 改进切分并单测/抽查两种样式的 PDF。  
2. 跑批量入库，确认 12 本成功或记录失败原因。  
3. 放开 API 与前端，用非一年级册走通出题。  
回滚：恢复一年级白名单；库中多册块可保留无害。

## Open Questions

无。若某本因扫描件无法提文本，记入失败列表，不降低「有单元就必须切开」的门槛。
