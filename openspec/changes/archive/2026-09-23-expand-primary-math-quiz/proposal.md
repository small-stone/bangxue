# Proposal

## Why

`book/小学/数学/人教版` 里已有一年级到六年级、上下册共 12 本 PDF，但向量库和出题接口仍只认一年级上册。家长在选题页看到其他年级，下一步却不可用，本地教材也用不了。

## What Changes

- 扩展单元切分：除现有「第 N 单元 / 孤行汉字序号」外，识别旧版人教目录式「数字序号 + 课题」（如四年级下册）。识别不到单元的书仍整本失败，不丢进无单元块。
- 提供批量入库命令：扫描 `book/小学/数学/` 下人教版 PDF，从路径与文件名解析年级、学期，逐本调用现有「一次一本」入库，向量仍用百炼 `qwen3.7-text-embedding`。已入库的一年级上册可被同五元组覆盖重写。
- **BREAKING（出题白名单）**：接口不再只接受一年级上册。凡是库里已有块的「小学 + 数学 + 人教版 + 年级 + 上下册」均可按单元出题；未入库或非数学/非人教版仍拒绝。
- 前端选题放开小学一年级至六年级、上册与下册（科目仍是数学、版本仍是人教版）；未入库组合给出明确说明。范围页继续按接口返回的单元列表选题。

## Capabilities

### New Capabilities

- `primary-math-quiz`: 家长可对已入库的小学数学人教版各册按单元出题，前端与接口的年级、学期范围一致。

### Modified Capabilities

- `textbook-ingest`: 切分须覆盖 2022 修订版与旧版人教目录式单元；并提供针对 `book/小学/数学` 的批量入库，仍保持一次一本、同五元组覆盖。

## Impact

- 前端：`draft` / 选题页放开年级与学期；文案从「只能一年级上册」改为「仅小学数学人教版已入库册」。初中、语文等仍不可继续。
- FastAPI：`list_units` / `load_unit_text` / `POST /api/quizzes` 按库内是否有块放行，不再写死一年级。出题仍同步、仍用 `qwen3.7-plus`。批量入库可能连续多次调 embedding，耗时会变长，不改成 SSE。
- Agent A：提示词改为对应年级的小学数学，仍只依据给定课文。Agent B、对话入口不在本期。
- 数据：`textbook_chunks` 增加多册块；向量维度保持 1024。`book/` 仍不进 git。
- 与进行中的 `add-grade1-quiz-screens`：该变更规格里「只能一年级」将被本变更取代。与 `wire-agent-harness`、`add-structured-quiz-illustrations` 无直接冲突。

## Non-goals

- 不入库初中、其他科目或其他版本（目录里也没有）。
- 不做向量相似度检索；仍按家长选的单元名取课文。
- 不开放对话出题、登录、判分、插图出题、LangGraph Checkpointer。
- 不把 PDF 提交进仓库。
