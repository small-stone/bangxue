# 核心流程效果图（移动端 Web）

对应 `REQUIREMENTS.md`：**两种出题入口 + 共用下游流程**。

按 [mobile-app-ui-design](https://github.com/ceorkm/mobile-app-ui-design) 规范：60/30/10 配色、8pt 网格、拇指热区主按钮、Peak-End 情绪反馈。

## 两套视觉

| 方案 | 目录 | 风格 |
|------|------|------|
| **A · 珊瑚橙**（当前主方案） | 本目录根下 `mockup-*.png` | 轻快活力，暖白 + 珊瑚橙 |
| **B · 墨金纸感** | [`alt-ink-amber/`](./alt-ink-amber/) | 书房纸感，石纸底 + 琥珀金选中/CTA |

两套信息架构与流程一致，仅视觉不同，便于选型。

---

## 方案 A · 珊瑚橙

| 角色 | Token | 用途 |
|------|-------|------|
| 60% 底色 | `#FAFAF8` + 淡珊瑚径向光晕 | 页面背景 |
| 30% 结构色 | `#1C1917` 暖炭黑 | 标题与正文 |
| 10% 强调色 | `#FF6B4A` 珊瑚橙 | 主 CTA、选中态、进度、得分 |
| 中性辅色 | `rgba(28,25,23,0.06)` | 未选中图标底、标签 |
| 错误 | `#E85D5D` | 错题态 |

原则：不用绿 / 蓝点缀；双入口并列；主操作在拇指热区；对话页确认在结果卡内、输入区贴底。

源文件：`_html/screens.html`（`node _html/capture.cjs`）

## 出题入口（需区分）

| 顺序 | 文件 | 页面 | 说明 |
|------|------|------|------|
| 0 | `mockup-00-home.png` | 首页 | 并列入口：**按教材出题** / **对话出题**；待办 + 最近练习（来源标签） |
| 1a | `mockup-01-select.png` | 按教材出题 | 方式 A：学段 / 年级 / 科目 / 版本 |
| 1b | `mockup-01b-chat.png` | 对话出题 | 方式 B：多轮对话 → 确认生成 PDF |
| 2 | `mockup-02-range.png` | 选择出题范围 | 仅方式 A：单元 / 半学期 / 整学期 |
| 3 | `mockup-03-config.png` | 出题设置 | 题量、难度、题型、答案卷开关 |

## 共用下游（两种方式汇合后）

| 顺序 | 文件 | 页面 | 说明 |
|------|------|------|------|
| 4 | `mockup-04-pdf.png` | 练习卷已生成 | 预览、下载 PDF / 答案卷（流程 Ending） |
| 5 | `mockup-05-upload.png` | 拍照上传答卷 | 拍照或相册、多页上传 |
| 6 | `mockup-06-result.png` | 判分结果 | 总分庆祝、逐题对错、错题入口（流程 Peak） |

## 流程

```
首页
 ├─ 按教材出题 → 选题 → 范围 → 设置 → 出题确认 ─┐
 └─ 对话出题   → 多轮对话 → 出题确认 ───────────┴─→ PDF → 拍照 → 看分
```
